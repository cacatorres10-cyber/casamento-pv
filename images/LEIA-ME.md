# As imagens da página

A página procura todos os arquivos nesta pasta (`images/`). Os nomes são exatamente os
mesmos que a página antiga usava no ar, então dá para copiar a pasta `images/` da
hospedagem atual para cá e tudo aparece sozinho.

Enquanto um arquivo não existir, o slot vira um retângulo listrado dizendo qual imagem
está faltando. A página nunca fica com ícone de imagem quebrada.

metade das noivas abre no 4G.

nome ou número.
